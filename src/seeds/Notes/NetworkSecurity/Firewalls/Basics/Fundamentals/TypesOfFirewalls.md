# The Different Types of Firewalls

<hr class="dividerSection" />

### Software vs Hardware Firewalls

<hr class="dividerSection" />

Firewalls generally come in two forms:

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li><span class="emphasis">Software firewalls</span> (also called <span class="secondEmphasis">host-based firewalls</span>), run as a program on an individual device, filtering traffic for that device specifically.</li>
    <li><span class="emphasis">Hardware firewalls</span>, dedicated physical devices that filter traffic for an entire network, typically sitting at the network's edge.</li>
  </ul>
</div>

<hr class="dividerSection" />

### Next-Generation Firewalls (NGFW)

<hr class="dividerSection" />

Firewalls are known as <span class="emphasis">Next-Generation Firewalls (NGFW)</span> when they include more modern and advanced filtering capabilities beyond basic rule-based traffic control.

<hr class="dividerSection" />

### Examples of Physical Firewalls

<hr class="dividerSection" />

Two examples of Cisco physical firewall devices are the <span class="emphasis">ASA 5500-X</span> and the <span class="emphasis">Firepower 2100</span>.

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li><span class="emphasis">ASA</span> stands for <span class="secondEmphasis">Adaptive Security Appliance</span>, Cisco's classic, traditional physical firewall.</li>
    <li>Even so, modern ASAs include features typical of <span class="emphasis">next-generation firewalls (NGFW)</span>, such as an <span class="emphasis">Intrusion Prevention System (IPS)</span>.</li>
    <li>The <span class="emphasis">Firepower 2100</span> series is another example of a next-generation firewall.</li>
  </ul>
</div>
