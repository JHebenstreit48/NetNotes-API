# Decks and Importing Flashcards

<hr class="dividerSection" />

### Creating a Deck

<hr class="dividerSection" />

When Anki is first opened, a default deck exists with 0 cards in it.

The <span class="emphasis">Create Deck</span> button at the bottom of the app lets you name a new deck, for example, a deck named "CCNA" for CCNA-related flashcards.

Creating a new deck this way replaces the default deck that was present when the app first opened.

<hr class="dividerSection" />

### Importing Flashcards

<hr class="dividerSection" />

Flashcards can be imported in two ways:

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>Clicking the <span class="emphasis">Import File</span> button at the bottom of the app.</li>
    <li>Going to the <span class="emphasis">File</span> menu and selecting <span class="emphasis">Import File</span>.</li>
  </ul>
</div>

Either method allows you to import one or more files or decks into Anki.

<hr class="dividerSection" />

### Parent Decks and Sub-Decks

<hr class="dividerSection" />

A deck such as "CCNA" is considered the <span class="emphasis">parent deck</span>. You can import as many sub-decks as needed, each with its own set number of flashcards.

Imported decks are not automatically nested under the parent deck. To make a deck a sub-deck, click it and drag and drop it onto the parent deck.

Once nested, a <span class="emphasis">+</span> icon appears to the left of the parent deck's name.

Clicking the <span class="emphasis">+</span> icon expands the parent deck to show each individual sub-deck, along with the actual number of cards in each one.
