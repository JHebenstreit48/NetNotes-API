# What Is Labbing, and Why Packet Tracer?

<hr class="dividerSection" />

### What Does "Labbing" Mean?

<hr class="dividerSection" />

In IT, <span class="emphasis">labbing</span> refers to hands-on practice with the technology you are studying.

For the CCNA certification specifically, labbing means configuring Cisco routers, switches, and overall network configurations.

<hr class="dividerSection" />

### Why Not Just Use Real Hardware?

<hr class="dividerSection" />

You can buy actual physical routers and switches, hardware branded by Cisco, but this can be very expensive and inconvenient.

<hr class="dividerSection" />

### Cisco Packet Tracer

<hr class="dividerSection" />

Cisco Packet Tracer is a <span class="emphasis">network simulation</span> and <span class="emphasis">visualization</span> tool used to practice configuration and troubleshooting without needing physical equipment.

It is free and easy to set up.

It is designed for:

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>Students with <span class="emphasis">no networking background</span></li>
    <li>Students with <span class="emphasis">some networking experience</span></li>
    <li>Learners enrolled in courses that require Packet Tracer labs</li>
  </ul>
</div>

Packet Tracer lets you:

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>Build a network from scratch</li>
    <li>Use pre-built sample networks</li>
    <li>Complete guided lab activities and assignments</li>
    <li>Practice introductory <span class="emphasis">IoT</span> and <span class="emphasis">Cybersecurity</span> workflows (depending on the activity)</li>
  </ul>
</div>

Packet Tracer is not a replacement for real hardware practice, but it is extremely useful for learning concepts, testing ideas, and building confidence before touching physical gear.
