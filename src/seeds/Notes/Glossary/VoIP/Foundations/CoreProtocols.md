## VoIP: Core Protocols

<hr class="dividerSection" />

## SIP (Session Initiation Protocol)

<hr class="dividerSection" />

<span class="emphasis">SIP</span> is an application layer signaling protocol used to initiate, manage, and terminate VoIP calls. It handles call setup and teardown but does not carry voice data.

## RTP (Real-Time Transport Protocol)

<hr class="dividerSection" />

<span class="emphasis">RTP</span> is a protocol used to deliver audio and video over IP networks in real time. It carries the actual voice or video payload during a VoIP call.

## RTCP (Real-Time Transport Control Protocol)

<hr class="dividerSection" />

<span class="emphasis">RTCP</span> is a companion protocol to RTP that monitors transmission quality and provides feedback on packet loss, jitter, and round-trip delay.

## SRTP (Secure Real-Time Transport Protocol)

<hr class="dividerSection" />

<span class="emphasis">SRTP</span> is an encrypted version of RTP that provides confidentiality and authentication for voice and video streams using AES encryption.
