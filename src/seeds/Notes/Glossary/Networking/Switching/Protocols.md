## Switching: Protocols

<hr class="dividerSection" />

## CDP (Cisco Discovery Protocol)

<hr class="dividerSection" />

<span class="emphasis">CDP</span> is a Cisco proprietary Layer 2 protocol used to discover directly connected Cisco devices. Enabled by default on all Cisco devices.

## LLDP (Link Layer Discovery Protocol)

<hr class="dividerSection" />

<span class="emphasis">LLDP</span> is a vendor-neutral Layer 2 neighbor discovery protocol defined in IEEE 802.1AB. Supported across multi-vendor environments. Not enabled by default on Cisco devices.

## STP (Spanning Tree Protocol)

<hr class="dividerSection" />

<span class="emphasis">STP</span> is a Layer 2 protocol defined in IEEE 802.1D that prevents network loops in switched Ethernet networks by electing a root bridge and blocking redundant paths.

## VTP (VLAN Trunking Protocol)

<hr class="dividerSection" />

<span class="emphasis">VTP</span> is a Cisco proprietary protocol that propagates VLAN configuration across a switched network automatically, reducing the need to manually configure VLANs on every switch.
