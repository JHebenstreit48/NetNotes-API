# Application Layer: Messaging

<hr class="dividerSection" />

## SMTP (Simple Mail Transfer Protocol)

<hr class="dividerSection" />

<span class="emphasis">SMTP</span>: is used by an email client to send messages to its local mail server, and between mail servers to relay messages to their destination. It operates on <span class="codeSnip">TCP port 25</span>.

## IMAP (Internet Message Access Protocol)

<hr class="dividerSection" />

<span class="emphasis">IMAP</span>: allows an email client to access and manage messages stored on a mail server, rather than downloading and removing them, so the same mailbox stays consistent across multiple devices. The current version, <span class="emphasis">IMAP4</span>, operates on <span class="codeSnip">TCP port 143</span>.

## Text Messaging

<hr class="dividerSection" />

<span class="emphasis">Text Messaging</span>: refers to real-time messaging between users over the internet, delivered through web-based clients built into social media or collaboration platforms, or through standalone apps such as WhatsApp, Slack, or Discord.
