# Application Layer: Web & DNS

<hr class="dividerSection" />

## HTTP (Hypertext Transfer Protocol)

<hr class="dividerSection" />

<span class="emphasis">HTTP</span> is an application layer protocol used to transfer hypertext data between a client (browser) and a server, operating unencrypted on <span class="codeSnip">port 80</span>.

## HTTPS (Hypertext Transfer Protocol Secure)

<hr class="dividerSection" />

<span class="emphasis">HTTPS</span> is the secure version of HTTP, encrypting communication using TLS/SSL and operating on <span class="codeSnip">port 443</span>. It ensures data confidentiality, integrity, and server authentication.

## DNS (Domain Name System)

<hr class="dividerSection" />

<span class="emphasis">DNS</span> is a server-based system that resolves human-readable domain names into IP addresses, allowing devices to reach hosts by name instead of requiring users to know raw IP addresses.
