# Common Cisco Router Models and Their Interface Layouts

<hr class="dividerSection" />

### ISR Series Overview

<hr class="dividerSection" />

Cisco's <span class="emphasis">Integrated Services Router (ISR)</span> line includes several models commonly seen in enterprise and small business environments.

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li><span class="emphasis">ISR 1000</span></li>
    <li><span class="emphasis">ISR 900</span></li>
    <li><span class="emphasis">ISR 4000</span></li>
  </ul>
</div>

<hr class="dividerSection" />

### Interface Placement

<hr class="dividerSection" />

Interface placement varies by model.

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>The <span class="emphasis">ISR 1000</span> and <span class="emphasis">ISR 4000</span> have their network interfaces on the back of the unit.</li>
    <li>The <span class="emphasis">ISR 900</span> has its network interfaces on the front of the unit.</li>
  </ul>
</div>

<hr class="dividerSection" />

### Interface Count vs Switches

<hr class="dividerSection" />

Routers typically have fewer network interfaces than switches, though this is not always the case.
