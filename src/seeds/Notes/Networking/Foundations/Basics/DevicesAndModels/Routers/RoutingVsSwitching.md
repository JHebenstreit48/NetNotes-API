# Routers vs Switches: Two Different Jobs

<hr class="dividerSection" />

### What Each Device Actually Does

<hr class="dividerSection" />

A <span class="emphasis">router</span> does what the name implies, it routes traffic from one LAN to another, typically via the internet.

A <span class="emphasis">switch</span>, by contrast, only forwards traffic within a single LAN.

  <span class="emphasis">See:</span>
  <a href="/switching/basics/fundamentals/layer-2-switching" target="_blank" rel="noopener noreferrer">Switching → Basics → Fundamentals → Layer 2 Switching</a>

<hr class="dividerSection" />

### Why This Distinction Matters

<hr class="dividerSection" />

A switch does not provide connectivity between separate LANs or over the internet, that job belongs entirely to the router.

This is why every host needing to reach a remote network relies on its <span class="emphasis">default gateway</span>, the router interface on its own LAN, rather than the switch it happens to be plugged into.
