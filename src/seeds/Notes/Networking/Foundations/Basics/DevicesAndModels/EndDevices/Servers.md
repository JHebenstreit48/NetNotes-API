# Servers as End Hosts

<hr class="dividerSection" />

### What Is a Server?

<hr class="dividerSection" />

A <span class="emphasis">server</span> is an end host itself, not a networking device used to connect other end hosts together.

This distinction matters because it's easy to assume any large or important-looking piece of hardware in a network diagram is a networking device, but a server's role is to provide services or resources to clients, the same as a PC requesting a webpage or a file, just on the other side of that request.

<hr class="dividerSection" />

### Servers vs Networking Devices

<hr class="dividerSection" />

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>A <span class="emphasis">networking device</span> (switch, router, firewall) moves, directs, or filters traffic between other devices.</li>
    <li>A <span class="emphasis">server</span> is one of the endpoints that traffic is actually being sent to or from.</li>
  </ul>
</div>

<hr class="dividerSection" />

### Common Server Roles

<hr class="dividerSection" />

Not every server holds a database, that's just one specific role among several. A server's defining trait is providing a service or resource to requesting clients, not storing data specifically.

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li><span class="emphasis">File servers</span>, store and share files</li>
    <li><span class="emphasis">Print servers</span>, manage shared network printers</li>
    <li><span class="emphasis">Web servers</span>, serve web content</li>
    <li><span class="emphasis">Database servers</span>, store and manage structured data</li>
    <li><span class="emphasis">DNS servers</span>, resolve domain names to IP addresses</li>
    <li><span class="emphasis">DHCP servers</span>, assign IP addresses dynamically</li>
    <li><span class="emphasis">Mail servers</span>, handle sending and receiving email</li>
  </ul>
</div>
