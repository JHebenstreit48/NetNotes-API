# What Networking Actually Means

<hr class="dividerSection" />

### What is Networking?

<hr class="dividerSection" />

Networking is the process of <span class="emphasis">connecting devices</span> to share <span class="emphasis">data</span> and <span class="secondEmphasis">resources</span>.

It enables communication and collaboration between users and systems across small or large distances.

Devices in a network take on one of two main roles:

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li><span class="emphasis">Client</span>, requests <span class="secondEmphasis">services</span> or <span class="secondEmphasis">data</span>.</li>
    <li><span class="emphasis">Server</span>, provides <span class="secondEmphasis">services</span> or <span class="secondEmphasis">data</span>.</li>
  </ul>
</div>

Real-world examples:

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>A <span class="emphasis">printer</span> on a home network allows multiple devices to send print jobs wirelessly.</li>
    <li>A <span class="emphasis">company network</span> enables employees to share files and access cloud-based applications.</li>
    <li><span class="emphasis">Online gaming servers</span> connect players from around the world.</li>
  </ul>
</div>

### The Client-Server Model

<hr class="dividerSection" />

<div class="centeredNumberedList">
  1. **Clients**

  <div class="centeredBullet">
    <ul class="diamondBullets fullWidthBullet">
      <li>Initiate <span class="secondEmphasis">communication</span> by making requests, such as opening a webpage or accessing a shared file.</li>
    </ul>
  </div>

  2. **Servers**

  <div class="centeredBullet">
    <ul class="diamondBullets fullWidthBullet">
      <li>Respond to these requests, providing <span class="secondEmphasis">data</span> or <span class="secondEmphasis">resources</span>.</li>
    </ul>
  </div>
</div>

Real-world example:

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>A <span class="emphasis">web browser (client)</span> requests a webpage from a <span class="emphasis">web server</span>.</li>
    <li>A <span class="emphasis">company laptop</span> accesses a shared document from a <span class="emphasis">file server</span>.</li>
  </ul>
</div>
