# Why Standards Matter

<hr class="dividerSection" />

With the increasing number of new devices and technologies coming online, how is it possible to manage all the changes and still reliably deliver services such as email?

The answer is <span class="emphasis">internet standards</span>.

A <span class="emphasis">standard</span> is a set of rules that determines how something must be done.

Networking and internet standards ensure that all devices connecting to the network implement the same set of rules or protocols in the same manner.

Using standards, it is possible for different types of devices to send information to each other over the internet.

For example, the way in which an email is formatted, forwarded, and received by all devices is done according to a standard.

If one person sends an email via a personal computer, another person can use a mobile phone to receive and read the email as long as the mobile phone uses the same standards as the personal computer.

<hr class="dividerSection" />

## How Internet Standards Are Created (RFCs)

<hr class="dividerSection" />

An internet standard is the end result of a comprehensive cycle of <span class="emphasis">discussion, problem solving, and testing</span>.

When a new standard is proposed, each stage of the development and approval process is recorded in a numbered <span class="emphasis">Request for Comments (RFC)</span> document so that the evolution of the standard is tracked.

RFCs for internet standards are published and managed by the <span class="emphasis">Internet Engineering Task Force (IETF)</span>.

<hr class="dividerSection" />

## Common Standards Bodies (High-Level)

<hr class="dividerSection" />

Different organizations support standards across different parts of networking.

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li><span class="emphasis">IETF</span> — publishes RFCs and standardizes many core internet protocols.</li>
    <li><span class="emphasis">IEEE</span> (<span class="secondEmphasis">Institute of Electrical and Electronics Engineers</span>) — defines many LAN/WLAN technical standards (ex: 802.3 Ethernet, 802.11 Wi-Fi).</li>
    <li><span class="emphasis">ICANN</span> — coordinates global domain names and IP-related resources.</li>
    <li><span class="emphasis">IANA</span> — manages core internet registries (IP allocations, protocol parameters, etc.).</li>
    <li><span class="emphasis">ITU</span> — develops global telecom standards (especially carrier and international telecom space).</li>
    <li><span class="emphasis">TIA</span> — defines many cabling and physical infrastructure standards (ex: wiring specs).</li>
  </ul>
</div>

These organizations are referenced again in specific sections throughout the notes (Ethernet, Wi-Fi, cabling, routing, etc.).

This page provides the high-level overview, while other pages cover how each standard works in practice.
