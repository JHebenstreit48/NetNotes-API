# T568A vs T568B

<hr class="dividerSection" />

## Ethernet Wire Color Coding

<hr class="dividerSection" />

Ethernet twisted-pair cables contain <span class="emphasis">four color-coded wire pairs</span>, for a total of <span class="emphasis">eight wires</span>.

Each pair consists of:

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>One <span class="emphasis">solid-colored wire</span></li>
    <li>One <span class="emphasis">white wire with a matching color stripe</span></li>
  </ul>
</div>

Example pairs:

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>White/Orange + Orange</li>
    <li>White/Green + Green</li>
    <li>White/Blue + Blue</li>
    <li>White/Brown + Brown</li>
  </ul>
</div>

These pairs must be placed in a specific order inside the RJ-45 connector.

Incorrect ordering can prevent the cable from functioning properly.

## Why Wire Order Matters

<hr class="dividerSection" />

Wire order determines:

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>Signal integrity</li>
    <li>Pair matching</li>
    <li>Cable type (straight-through or crossover)</li>
  </ul>
</div>

Incorrect ordering can cause:

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>Link failures</li>
    <li>Packet errors</li>
    <li>Reduced speeds</li>
  </ul>
</div>
