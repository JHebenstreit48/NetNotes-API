# Communication Standards

<hr class="dividerSection" />

### Why Standards Matter

<hr class="dividerSection" />

Communication standards define shared rules so devices can transmit data in a compatible way.

Without standards, equipment from different vendors would not reliably communicate.

<hr class="dividerSection" />

### Wired Communication Standards (Ethernet)

<hr class="dividerSection" />

Most wired LANs use <span class="emphasis">Ethernet</span>, standardized by the <span class="emphasis">IEEE</span> under the <span class="emphasis">802.3</span> family.

Ethernet standards define things like:

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>Physical media (copper or fiber)</li>
    <li>Link speed options</li>
    <li>Distance limitations</li>
    <li>Signaling requirements for the medium</li>
  </ul>
</div>

<hr class="dividerSection" />

### Wireless Communication Standards (Wi-Fi)

<hr class="dividerSection" />

Wireless networking commonly uses <span class="emphasis">Wi-Fi</span>, standardized by the <span class="emphasis">IEEE</span> under the <span class="emphasis">802.11</span> family.

At the Physical layer, wireless uses the <span class="emphasis">air (RF)</span> as the transmission medium.

For deeper Wi-Fi concepts:

<div class="xrefBox">
  <span class="emphasis">See:</span>
  <a href="/networking/wireless/basics/80211/wireless-standards" target="_blank" rel="noopener noreferrer">Wireless → Basics → 802.11 Fundamentals → Wireless Standards</a>
</div>

<hr class="dividerSection" />

### Media vs Standards

<hr class="dividerSection" />

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li><span class="emphasis">Media</span> is the physical path (copper, fiber, air)</li>
    <li><span class="emphasis">Standards</span> are the rules for how devices use that path</li>
  </ul>
</div>

Both are needed for reliable communication.

<hr class="dividerSection" />

### Summary

<hr class="dividerSection" />

Communication standards provide:

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>Interoperability between devices</li>
    <li>Predictable performance expectations</li>
    <li>A foundation for higher-layer networking</li>
  </ul>
</div>
