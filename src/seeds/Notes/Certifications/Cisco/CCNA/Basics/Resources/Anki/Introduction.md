# Getting Started with Anki

<hr class="dividerSection" />

### Spaced Repetition Software

<hr class="dividerSection" />

<span class="emphasis">Anki</span> is an example of <span class="emphasis">SRS</span>, <span class="secondEmphasis">Spaced Repetition Software</span>.

It allows you to create flashcards, as well as import pre-made flashcards, such as ones provided by an instructor or course.

Anki's algorithm schedules flashcard reviews for you each day to help information stay in your long-term memory.

Using flashcards is optional, it is not a required study method for any particular course.

<hr class="dividerSection" />

### Desktop Platforms

<hr class="dividerSection" />

Anki's free desktop version is available for all major platforms:

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li><span class="emphasis">Windows</span>, Windows 10+ (x64) or Windows 11 (ARM)</li>
    <li><span class="emphasis">macOS</span>, macOS 13+ (Apple Silicon) or macOS 13+ (Intel)</li>
    <li><span class="emphasis">Linux</span>, Linux (x64) 2022+ or Linux (ARM) 2024+</li>
  </ul>
</div>

Even if a device runs a newer OS, hardware compatibility matters. For example, a CPU that does not support ARM builds will need the standard x64 build instead, even on a machine running Windows 11.

<hr class="dividerSection" />

### Mobile Platforms

<hr class="dividerSection" />

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li><span class="emphasis">iOS</span>, AnkiMobile is the official app and must be purchased. Purchases help fund Anki's development.</li>
    <li><span class="emphasis">Android</span>, AnkiDroid is free and developed by contributors. Donations help fund AnkiDroid's development.</li>
  </ul>
</div>

<hr class="dividerSection" />

### Web App Alternative

<hr class="dividerSection" />

A web app version is available for free at <span class="codeSnip">apps.ankiweb.net</span>.

This provides a free way to use Anki on an iPhone without purchasing AnkiMobile, though its features are limited compared to the full native iOS app.

<hr class="dividerSection" />
